# Real-Time AI Chat Performance - Notes From Building

Latency kills immersion faster than a bad response.

A clever reply that arrives after eight seconds breaks the spell. Perceived responsiveness is part of the character.

Streaming tokens, warm context caches, and tight retrieval budgets are what keep a conversation feeling alive.

Speed is not a technical metric here - it is part of the fiction.

These are the lessons that only show up once you ship. [explore Pogee](https://pogee.ai/).
